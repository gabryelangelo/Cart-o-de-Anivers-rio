# Feliz Aniversario, Mona!

Cantinho comemorativo criado na web para celebrar o aniversario da Mona, reunir memorias, mensagens e interacoes especiais em uma pagina publicada na Vercel.

## Destaques da Pagina

- Cartao principal com dedicacao especial e botao interativo para soltar confetes na tela.
- Secao de mensagem para o novo ciclo, pensada para acompanhar o clima da comemoracao.
- Identidade visual escura com detalhes em rosa, tipografia de destaque e animacoes leves.
- Icone personalizado na aba do navegador e hospedagem continua via GitHub e Vercel.

## Organizacao do Projeto

- `index.html`: estrutura principal da pagina, textos do cartao e configuracao do `favicon`.
- `frontend/js/index.js`: interacoes da interface, incluindo o efeito de confetes.
- `frontend/images/`: imagens, audios e arquivos de midia usados na experiencia.

## Como Rodar Localmente

1. Abra a pasta do projeto no VS Code.
2. Abra o arquivo `index.html` no navegador ou inicie o **Live Server** para testar as mudancas na hora.

## Publicacao

O site esta publicado em `https://cartaodeaniversario.vercel.app`. Sempre que um novo `commit` entra na branch principal no GitHub, a Vercel atualiza o deploy automaticamente.
